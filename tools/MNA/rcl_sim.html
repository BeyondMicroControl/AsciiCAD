Series RLC Transient Simulator (stamp-based)

This is a minimal “SPICE-like” core: each component is a port model that defines a branch current/voltage law and then stamps its contribution into a global system built from: KCL at nodes + extra equations for extra unknowns (MNA-style).

Circuit (series RLC to ground): Vs → R → L → C → GND.
Nodes: 0 = ground (fixed 0V), V1 = source plus (fixed Vs), V2 = between R and L, V3 = between L and C.

Output table columns: time, voltage across the resistor V_res = V1 − V2, current through the resistor I_res = (V1 − V2)/R. (In this series circuit, that is also the inductor/capacitor series current.)

Math recap (what the stamp engine is solving)

Port conventions: Each 2-pin device has pins (a,b) with node voltages (Va,Vb). Define:

  • Branch voltage: v = Va − Vb
  • Branch current: i is positive from a → b
  • KCL uses “currents leaving node”: leaving at node a is +i, leaving at node b is −i

Resistor: i = (Va − Vb)/R

Capacitor: i = C * d/dt (Va − Vb)

Inductor: v = L * d/dt (i)

For capacitors, we discretize dv/dt; for inductors, we discretize di/dt. The chosen integration method (BE/TR/BDF2) is an analysis-level object oINTEGRATOR. Devices remain method-agnostic by asking the integrator for the algebraic form to stamp.

Unknown vector x:

  • Unknown node voltages (here V2, V3)
  • Extra unknowns introduced by devices (here: inductor branch current iL)

The residual vector r is arranged so that:

  • r[node-unknown] is KCL at that node (sum currents leaving = 0)
  • r[extra-unknown] is the constitutive equation for that extra unknown (e.g., inductor v=L di/dt)
