Series RC Transient Simulator (Stamp-based, Old-school JS objects)

This is a minimal “SPICE-like” core: every component is a port model that defines a branch current i = f(v, v_prev, dt, ...) and then contributes (stamps) its effect into the global KCL residual and Jacobian.

Circuit: Vs=5V → R=10kΩ → C=10µF → back to source (-, GND).
Nodes: 0 = ground (fixed 0V), V1 = source plus (fixed Vs), V2 = unknown node between R and C.

Output table columns: time, voltage across the resistor V_res = V1 − V2, current through the resistor I_res = (V1 − V2)/R.

Math recap (what the stamp engine is solving)

Port conventions: Each 2-pin device has pins (a,b) with node voltages (Va,Vb). Define:

  • Branch voltage: v = Va − Vb
  • Branch current: i is positive from a → b
  • KCL “currents leaving node”: leaving at node a is +i, leaving at node b is −i

Resistor model (Ohm): i = (Va − Vb)/R

Capacitor model: i = C * d/dt (Va − Vb)

Backward Euler discretization for the capacitor:

Backward Euler (BE): d/dt (v) ≈ (v(n) − v(n−1)) / dt ⇒ i(n) ≈ (C/dt) * (v(n) − v(n−1))

Trapezoidal (TR): v(n) = v(n−1) + (dt/2C) * ( i(n) + i(n−1) ) ⇒ i(n) ≈ (2C/dt) * (v(n) − v(n−1)) − i(n−1)

Gear / BDF2: d/dt (v) ≈ (3v(n) − 4v(n−1) + v(n−2)) / (2dt) ⇒ i(n) ≈ C * (3v(n) − 4v(n−1) + v(n−2)) / (2dt)

Network law: KCL at every unknown node: sum of currents leaving node = 0.

This becomes a system of equations F(x)=0 in the unknown node voltages x. We solve by Newton: J(x) * dx = -F(x). For our linear RC, Newton converges in one iteration; the framework still supports nonlinear devices later.
