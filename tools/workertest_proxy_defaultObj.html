Worker URL Command Tester (Proxy scope + defaultObj)

Params:
  • command (required): JS snippet, usually wrapped in { ... }
  • defaultObj (optional): object name to proxy for unqualified calls, e.g. oASC or oCOM
Examples (encoded):
  • ?defaultObj=oASC&command=%7Bfreeform(0,0,'%2B')%7D
  • ?defaultObj=oCOM&command=%7BisDoubleWidthChar('%2B')%7D
  • ?command=%7BoCOM.isDoubleWidthChar('%2B')%7D
  • ?command=%7Bbox(0,0,3,3,BOX_DOUBLE)%7D
